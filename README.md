## 🔧 How to Use

1. **Push the code** to your GitHub repository.

2. **Manually trigger** the workflow:
   - Go to the Actions tab
   - Select "VM Placement Experiments"
   - Click "Run workflow"
   - Optionally choose parameters

3. **Automatically runs** on every push to `main`.

4. **Results are**:
   - Uploaded as artifacts (downloadable)
   - Committed to the repo in `results/`
   - Displayed in the README
